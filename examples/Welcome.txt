# Writing

Type your essay as plain paragraphs. Use **bold** and *italic* in the text, and write equations as plain text, for example $x^2 + 3x = 10$.

A line with only an equation is centred on its own:

$sqrt(a^2 + b^2) = c$

# Blocks

# Sources

Add sources with `[@key]` and list them in a `:::sources` block, and the bibliography formats itself in APA, MLA, Harvard, Chicago or IEEE.
